Crash-proof by construction

  • Task-level isolation — every script runs inside its own asyncio task with a full try/except envelope; exceptions are logged to the terminal and die with the task, never with Quart.
  • Handler snapshot hygiene — the engine snapshots the client's event handlers before exec and purges everything the script added on stop. No ghost handlers, ever.
  • Compile pre-check — syntax errors are rejected in-route with the exact line number before any task is spawned.
  • Token-guarded registry — re-running a script on the same account awaits the old task's cancellation first; stale tasks can never evict their replacement.
  • Session persistence — atomic writes to sessions.json + templates.json; on boot, every saved account reconnects and re-authorizes through Telethon.
  • print() redirection — user prints are rerouted into the tagged live terminal, so debugging feels native.
Execution engine runs the code YOU paste — treat the dashboard as your own admin panel and restrict network access accordingly. Scripts should stay async-native; blocking sync calls would stall the shared event loop.
