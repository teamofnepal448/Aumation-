Hardening built in

  • Task isolation — compile pre-check, per-task try/except, handler snapshot + purge on stop, token-guarded registry.
  • Locked content never leaks — customer routes strip locked_content until an approved order matches the requester.
  • Admin tokens — constant-time credential compare, 12h expiry, X-Admin-Token header on every mutating route.
  • Session privacy — StringSession blobs are length-logged only, never returned by status or customer APIs.
  • Atomic JSON stores — tmp-write + os.replace, corrupt files self-heal to empty instead of crashing boot.
