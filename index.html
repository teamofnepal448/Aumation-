Production hardening, already inside

  • Full RPC error matrix — PhoneNumberInvalid, PhoneCodeInvalid/Expired, PasswordHashInvalid (2FA), FloodWait (returns retry-after), ApiIdInvalid, PhoneNumberBanned.
  • Session ID login hardened — malformed blob → 400, dead/revoked auth key → 401, duplicates rejected without leaking a second client, blob never logged nor returned.
  • Session lifecycle — pending clients live in a keyed dict, stale OTP attempts swept + disconnected by a Hypercorn background task.
  • Handler hygiene — start is idempotent-restart; stop detaches the exact NewMessage builder. No duplicate relay loops, ever.
  • Media-aware relay — photos, docs & video re-upload via send_file with re-branded captions; service messages skipped.
  • Connect timeout + graceful shutdown — 25s wait_for on connect; after_serving disconnects every Telethon client.
  • CORS enabled — drive the API from any origin; string sessions returned once at OTP verify, never re-exposed by /api/status.
Note: Render free instances restart on redeploy, evicting in-memory clients — simply re-run OTP or re-login with your saved StringSession. Persist sessions in your own secret store for zero-reconnect deploys.
